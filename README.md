# AriZeba — Full-Stack E-Commerce Web Application

AriZeba is a full-stack e-commerce web application developed as a portfolio project. It provides a complete online shopping experience for customers along with an admin dashboard for managing products, customers, orders, and sales analytics.

---

## ✨ Features

### 🛍️ Customer Features

- Browse products
- Product categories
- Product details
- Shopping cart
- Checkout system
- Customer information
- Order placement
- Order confirmation
- Order tracking
- My Orders
- Customer Account/Profile
- Responsive design for mobile and desktop

### 🔐 Admin Features

- Admin login
- Admin dashboard
- Total orders overview
- Total sales overview
- Pending orders
- Customer overview
- Sales analytics
- Revenue chart
- Best-selling products
- Order management
- Search and filtering
- Order status updates
- Order details
- Customer management
- Product management
- Add products
- Edit products
- Delete products
- Product images
- Product price
- Product category
- Product description
- Product stock/availability
